# model-ia-testing

Plataforma para automatizar pruebas de calidad observable sobre sistemas conversacionales.

## Estado

El repositorio se encuentra en fase de definición y diseño. La implementación del MVP aún no ha comenzado.

## Baseline actual

- Frente 1: requisitos del MVP refinados.
- Evaluación y calificación: pendientes de definición metodológica.
- Arquitectura: pendiente.
- Implementación: pendiente.
- CI/CD: requisito definido; implementación pendiente.

## Principio

> La IA interpreta evidencia; no reemplaza evidencia.

## Trazabilidad

El proyecto busca mantener la cadena:

`Requisito → Criterio de aceptación → Gherkin → Implementación → Prueba → CI → Evidencia → Resultado → Hallazgo → Reporte`
